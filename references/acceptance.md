# 桌面界面验收

按本轮变更影响选择检查项。局部文案或样式调整不要求检查所有窗口、平台与状态；窗口外壳、输入法或流式滚动的修改则需要对应运行环境的证据。

## 1. 阴影裁切诊断

涉及阴影或裁切边变化时，可用 [`scripts/clip-audit.js`](../scripts/clip-audit.js) 辅助定位。

1. 读取脚本，将整个函数交给当前浏览器工具的页面求值接口，或在控制台将它赋给变量后调用。不要假定所有工具都有同一个接口名称。
2. `{ root: '.screen' }` 检查目标根元素自身及其后代，祖先边界仍从根外继续追溯；根不存在或选择器无效时返回 `ok: false` 和 `error`。
3. `{ viewport: true }` 将文档的 CSS 视口纳入检查。它不是操作系统窗口物理像素、显示缩放或系统投影的测量工具。
4. 只检查当前实际计算样式。需要悬停、展开或动画状态时，先实际进入该状态，再运行；脚本不扫描样式表来伪造悬停状态。
5. 状态覆盖依改动选择，包含有风险的中间帧、长内容与溢出状态；不要机械要求每个改动都运行固定四种状态。

### 返回结果与解释

- `cut`：露出部分阴影后被截断的问题条数，按元素、阴影类型、祖先与方向计数，不是像素数。
- `hidden`：阴影边缘几乎完全被隐藏的问题条数，也需要判断是否符合设计。
- `issues[].clippedPx`：该方向估算越界距离，单位为 CSS 像素，不是被裁像素面积。
- `warnings` / `warningCount`：无法可靠测量的情况与数量，例如复杂裁切路径、遮罩、圆角、变换、滤镜、伪元素和影子树。
- `truncated`：返回详情超过 `max` 上限（默认 40），计数仍为完整数量，可增大上限或缩小范围后复查。
- `approximate: true`：使用几何估计与约三倍标准差的模糊范围，不能证明真实像素完整。
- `ok`：本次未发现上述问题或待复核项；即便为 true，也不代表未检查的状态、输入法或桌面窗口行为已通过。

**交付判断**：检查定位结果、真实截图和产品意图；修复非预期裁切，记录有意裁切及无法覆盖的边界。不得单独以 `cut === 0` 或 `ok === true` 作为通过证明。

### 已知范围

可诊断普通元素边框盒阴影与轴对齐的矩形祖先裁切，包括可滚动祖先。模糊半径是估计；本体已越过某条裁切边的滚动内容不在该边自动报错。图片的盒阴影仍围绕盒边界计算，不能用透明图片内容边界替代。

复杂裁切形状、透明内容滤镜、变换、伪元素和影子树不做像素级测量，遇到可识别的情况返回待复核项。关闭的影子树、内嵌文档、不可见状态、组合滤镜实际绘制范围和系统窗口投影需要其他工具或人工检查。静态几何不等于视觉验证。

## 2. 按改动选择验收

- **窗口外壳**：窗口按钮、拖拽与控件点击热区、透明边缘、平台缩放和图标尺寸。
- **输入框**：组字回车仅确认候选词；空格或点击选词后立即回车正常发送；连续回车、多个输入框互不影响；粘贴长文本后光标与滚动仍可用。
- **流式会话**：追加前记录跟随意图；回溯时不强拉底部；代码高亮和图片加载不造成双重滚动补偿。
- **分栏**：最小尺寸、键盘操作、取消拖拽恢复完整状态，指针取消及卸载释放监听。
- **任务与恢复**：状态来自实际事件，区分请求停止与确认停止；预览和落盘有清晰边界；重连不重复副作用；草稿与附件按会话隔离。
- **可访问性与动效**：键盘导航、焦点可见性、滚动发现性、高对比度和减弱动态效果符合本轮影响范围。

## 3. 最小交付记录

记录运行时与平台、本轮覆盖的状态、验证方法和实际结果；涉及视觉问题保留截图，涉及输入法说明真实设备与输入法。诊断输出是定位附件，不替代视觉与交互证据。

## 4. 本仓库回归

```sh
npm ci
npx playwright install chromium
npm test
```

测试采用 Playwright（浏览器自动化库）与 Node.js 内置测试运行器；仅为开发验证依赖，不进入诊断脚本运行环境。可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定已安装的 Chromium 可执行文件。

回归覆盖裁切、复杂形状待复核、输入法示例的事件逻辑及遮罩的真实计算样式。合成事件不等于真实输入法，浏览器检查也不等于 Electron / Tauri 原生窗口验收。
